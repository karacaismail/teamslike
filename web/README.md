# AURA — Web (Faz 1–10 · tüm yol haritası)

AI-orkestrasyon merkezli, multitenant, AI-first iletişim paneli. **Faz 1** (Kimlik + Tenant + AI Orkestrasyon) + **Faz 2** (Mesajlaşma) + **Faz 3** (Gerçek Zamanlı Toplantı) + **Faz 4** (Çeviri & Konuşma Zekâsı) + **Faz 5** (Telefon / UCaaS · PSTN) + **Faz 6** (Webinar & Canlı Etkinlik) + **Faz 7** (Zamanlama & Takvim · Cal.com/Calendly) + **Faz 8** (Omnichannel Müşteri Destek · Chatwoot) + **Faz 9** (Doküman & İşbirliği · Coda/Basecamp + Slack Canvas/Lists/Workflow/Clips) + **Faz 10** (Egemenlik, Güvenlik & Admin · federasyon/audit/politika/faturalama). Sadece frontend; zengin dummy data ile çalışır, FastAPI sözleşmesine uyumludur.

## Yığın
React 19 · Vite · TypeScript · Tailwind CSS v4 · Radix (shadcn-tarzı primitives) · react-router · TanStack Query · Zustand · i18next (en/tr) · Phosphor icons.

## Çalıştırma
```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm run typecheck
npm run build
```

> Demo modu: giriş ekranında herhangi bir e-posta ile devam edilir (gerçek auth yok).

## AI simülasyonu (güçlü)
- **Çok adımlı ajan:** komut/copilot'a istek → görünür adımlar (bağlam okuma → arama → analiz → yazma) sırayla "running → done", sonra cevap kelime-kelime stream, ardından **öneri zincirleri** (tıkla → yeni ajan run).
- **Niyet yönlendirme:** özet / taslak / çeviri / planlama / genel senaryoları (EN+TR anahtar kelimeyle).
- **Bağlam-farkında:** copilot aktif domain'i otomatik "grounding" alır; komut paleti `Cmd/Ctrl+K`.
- **Proaktif:** Dashboard'da copilot öneri kartları.

## UX simülasyonu (güçlü)
- **Canlı RBAC rol simülatörü:** Ayarlar → Demo rol (Sahip/Yönetici/Üye/Misafir). Değişince nav, komut paleti, AI ve ekranlar **anında** güncellenir (Misafir → AI ve çoğu domain kaybolur).
- **Tenant-branding canlı tema:** workspace değişince accent rengi (açık temada) anında yeniden temalanır; AAA korunur.
- **Bildirim merkezi** (okunmamış rozet, okundu işaretle), **toast** sistemi, **presence** (çevrimiçi/uzakta/çevrimdışı), **Members** sayfası (rol rozetleri + presence + davet — RBAC'li, izin yoksa "erişim yok").
- **Aktivite akışı** ve **ekip** kartları (dummy data).
- **Durum desenleri:** loading/empty/forbidden.

- **Yan panel:** Katılımcılar / Sohbet / Altyazı sekmeleri; tepki overlay'i.
- **Moderatör & kalıcı odalar:** **video rooms** oluştur/listele/katıl (Jitsi-style, kilit+bekleme+şifre); **host paneli** — toplantıyı kilitle, bekleme odası, katılımcı ekran/sohbet izni, **herkesi sustur**, **tüm elleri indir**, **herkes için bitir**; katılımcı bazında **spotlight**, **co-host yap**, **çıkar**, el indir; tile'larda **bağlantı kalitesi** göstergesi.
- **Toplantı-içi etkileşim (yeni):** **anket** (host başlatır → oy + canlı sonuç), **Q&A** (sor / upvote / host "yanıtlandı"), **whiteboard** (freehand SVG + renk + temizle), **kayıt özeti** (transkript + AI özet + aksiyon maddeleri + indir-mock) — Engage paneli + kontrol çubuğu butonları.

## Standartlar
- **WCAG 2.2 AAA:** min 1rem metin, ≥7:1 kontrast, ≥44px hedef, görünür odak, reduced-motion, renk-bağımsız durum (renk+ikon+etiket).
- **i18n:** birincil EN, ikincil TR; tam anahtar paritesi (TS ile zorlanır).
- **Component-based:** token → primitive (`@/components/ui`) → shell → domain; master değişimi tek noktadan yayılır.

## Mimari notlar
- `src/features/<context>/` → DDD feature-slice (Faz 2: `messaging`, Faz 3: `meetings` = types/data/store/components). Slice yalnızca `@/components/ui` master bileşenlerini tüketir, yeniden stillemez.
- `src/data/*` → tek kaynak (domains, roles, team, notifications, agentScenarios).
- `src/lib/mockApi.ts` → FastAPI sözleşmesini taklit eden in-memory katman. Gerçek backend gelince `httpClient` ile değiştir; ekran/iş mantığı sabit kalır.
- `src/store/*` → Zustand context'leri (auth+RBAC, tenant, ui, copilot, toast, notification).
- `src/lib/useCopilot.ts` → her yerden ajan tetikleme (plan çöz → dock aç → çok adımlı run).
- Tasarım token'ları `src/index.css` içinde `@theme inline` + `[data-theme]` ile runtime temalama.

## Çeviri & Konuşma Zekâsı (Faz 4 — kesişen servis, DDD feature-slice)
`src/features/intelligence/` — Faz 2/3'ü besleyen open-host servis (ASR+MT+LLM sözleşmesi; FastAPI'de SSE ile akar).
- **Transkript + çeviri:** konuşmacı-bazlı transkript; **70+ dil** hedef seçici + satır-içi çeviri + **"sesi koruyan"** rozeti (Google Meet ayırt ediciliği).
- **Duygu zaman çizelgesi:** SVG; **renk + ikon + etiket** (AAA, renk-yalnız değil).
- **AI scorecard** (Dialpad): konuşma oranı, duygu, soru, tempo (wpm), en uzun monolog, CSAT.
- **Intent analizi** (Demio/Dialpad): güven çubuğuyla tespit edilen niyetler.
- **Highlight reel:** karar/aksiyon/itiraz/soru anları → transkriptte **atla**.
- **Canlı koçluk (whisper):** RBAC — yalnız yöneticiler (`admin.access`); diğerleri kilitli not görür.
- **Canlı mod:** kaynak "canlı" iken transkript + duygu + koçluk sinyalleri zamanla akar (güçlü AI sim).
- **AI aksiyonları:** Özetle / Aksiyon maddeleri → copilot çok adımlı ajan. `/intelligence` rotası (lazy chunk).
- **Genişletme (rakip boşluğu):** **konuşmacı analitiği** (talk-time çubuğu / kişi-duygu / kesinti / dolgu kelime), **yapılandırılmış AI recap** (TL;DR + kararlar + aksiyon-sahibi → **sohbete gönder** cross-cut + sonraki adımlar — Zoom/Teams Intelligent Recap), **rubrik scorecard** (auto geç/kaldı — Dialpad AI Scorecards), **tahmini CSAT** + gerekçe, **trackers / Custom Moments** (keyword/rakip/konu isabetleri — Dialpad), **transkriptte arama + konuşmacı filtresi + kelime vurgusu**, **sesli dub** ("kendi dilinde dinle", sesi koruyan) + **dil otomatik algılama**.
- **Plan-tamamlama (§6 Faz 4 sözleşmesi):** **CoachingCueRaised → canlı whisper toast** (yalnız `admin.access`); **AnalysisReport** agregası + `GET /analysis/:id` mock sözleşmesi (`api.ts#fetchAnalysis`); **PII redaksiyon** (e-posta + uzun rakam dizileri maskeleme — uyum/compliance); **export** aksiyonu (transkript & özet). Bağlam köprüleri: Toplantı **EngagePanel → "Zekâda aç"**, Mesajlaşma müşteri kanalı **header → "Analiz et"** (`integration.useOpenIntelligence`).
- **Sertleştirme (mimari kapanış):** **`TranslationSession` agregası** ayrı `captionsStore` (aktif dil çiftleri + canlı altyazı tamponu, sesi-koruyan bayrağı); **tipli SSE olay katmanı** (`events.ts` + `stream.ts`) — `IntelEvent` ayrımlı birleşim = `caption.emitted`/`translation.ready`/`intel.sentiment`/`intel.coaching`/`intel.highlight`, `subscribeIntel` mock dispatcher (`EventSource`'a birebir geçer), store tek **`applyEvent`** yolu (**idempotent**, tekrarlı teslimde çoğaltmaz); **`GET /transcripts/:id`** ayrı sözleşme (`fetchTranscript`); **açık `Segment.translations` haritası** (`{lang:text}` — 70+ dil; en/tr + es/de örnek) `segmentText` ile çözümleniyor; **`mergeSegments`/`resolveLangPair`** saf util. `HighlightReel` artık store'dan beslenir (HighlightDetected → re-render).

## Telefon / UCaaS (Faz 5 — `Telephony` context, PSTN)
`src/features/telephony/` — taşıyıcı-agnostik UCaaS yüzeyi; REST + WS `call.*` sözleşmesi (mock → httpClient/WebSocket birebir geçer). Conversation Intelligence'ı (Faz 4) canlı koçluk için tüketir.
- **Dialer:** ≥44px tuş takımı (klavye + ekran okuyucu), `normalizeNumber` (DTMF / `00`→`+`), canlı `formatNumber` önizleme.
- **Çağrı durum makinesi (`callStore`):** `ringing → active ⇄ hold → ended`; `place/answer/hold/resume/transfer/hangup/toggleMute/tick`; **tipli `CallEvent`** (`call.placed/answered/ended/routed`, `voicemail.left`, `sms.received`) tek **`applyEvent`** yolu (**idempotent**); dışa giden çağrı için uzaktan açılma simülasyonu.
- **Global `ActiveCallBar`:** her ekranda kalıcı (shell'e monte) overlay; durum çipi (renk+ikon+etiket, AAA) + canlı süre (`aria-live`), sustur/beklet/aktar/kapat, gelen çağrıda cevapla/reddet, **Zekâ köprüsü** (canlı koçluk).
- **Görsel voicemail:** transkript + oynat (demo) + dinlendi işaretle. **SMS/MMS:** thread listesi + balon görünüm + hazır yanıtlar (`smsStore`: send/receive/markRead).
- **Çağrı yönlendirme (`RoutingRuleBuilder`):** find-me/follow-me kuralları (koşul→aksiyon: forward/voicemail/IVR) + bağlamla **canlı `evaluateRouting` önizleme**. `presenceToRouting` (presence→aksiyon). `/telephony` rotası (lazy chunk).
- **P0 sertleştirme (Teams/Zoom Phone paritesi):** **Çağrı kuyrukları** (`pbxStore` + `CallQueuePanel`) — ring stratejisi (`pickAgent`: simultaneous/round-robin/longest-idle), canlı bekleyenler, `enqueue`/`assignNext`. **Çok katmanlı IVR builder** (`IVRBuilder` + `ivrResolve` menü ağacı) + **mesai/tatil** (`isWithinHours`). **Warm (danışarak) aktarma + konferans** (`startConsult`/`completeTransfer`/`mergeConsult`/`cancelConsult` + `addToCall`). **Çağrı park/pickup**, **çağrı-içi DTMF** (`sendDtmf`), **kayıt yönetimi** (`toggleRecording` + onaylı `Recording`). **Çağrı analitiği** (`CallAnalytics`: `computeCallStats` hacim/cevapsız %/AHT + `volumeByHour` saatlik bar + kuyruk SLA). Hepsi global `ActiveCallBar`'a (record/park/DTMF/aktar-ekle) ve PhoneLayout sekmelerine (Kuyruklar/IVR/Analitik) bağlı.
- **P1 sertleştirme (ajan/yönetim derinliği):** **Süpervizör izleme** (`monitorAudio` listen/whisper/barge/takeover, `ActiveCallBar`'da RBAC `admin.access`). **Yetkinlik-bazlı yönlendirme** (`pickAgentBySkill` + `pbxStore.assignNextBySkill` + ajan skill etiketleri). **Spam/robocall etiketleme + engelleme** (`classifyCaller` trusted/unknown/spam/blocked, `blockNumber`/`unblock`, `CallHistory`+`ActiveCallBar` rozet). **MMS/grup SMS + değişkenli şablon + zamanlı gönderim** (`SmsMedia`, grup thread, `renderTemplate`, `scheduleSms`/`flushDue`). **Görsel voicemail karşılama + e-postaya ilet**. **Çağrı sonrası wrap-up/disposition** (`WrapUpCard` → `saveDisposition`, sonuç+not+etiket). **Rehber + favori/hızlı arama** (`searchContacts`, `directoryStore`, Rehber sekmesi). **Paylaşılan hat delegasyonu** (`Delegate` + `canActOnBehalf`).
